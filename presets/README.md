# 플레오스 세팅 저장본

`optical-settings.json`은 2026년 10월 6일 Git 기록을 위해 수집한 로컬 공유 세팅입니다.
현재 작업본과 이전 작업본별 전체 수치, 이름 붙인 판형 배리에이션,
카메라 프로필을 원본 그대로 포함합니다. 원래 저장일은 각 payload.updatedAt에 있습니다.

다른 컴퓨터에서 저장소를 받은 후 다음 명령으로 복원합니다.

```sh
node scripts/restore-presets.mjs
npm run dev
```

복원은 `.pleos/optical-state/`에 없는 세팅만 생성합니다.
이미 존재하는 세팅은 덮어쓰지 않습니다. 현재 A/B 통합안은
`http://127.0.0.1:5173/?look=hybrid-ab`에서 열 수 있습니다.

이전 사이트 실행 코드(`public/versions/`)는 별도의 로컬 보관본이며
이 세팅 백업에 포함되지 않습니다. 이전 세팅을 같은 렌더러로 확인하려면
해당 사이트 버전도 함께 옮겨야 합니다.

브라우저에만 저장된 상단 메뉴의 이름 붙인 설정, 즐겨찾기 및 게이트 설정은
이 로컬 공유 파일 수집에 포함되지 않습니다. 판형 배리에이션과 구분됩니다.
