# 디멘션 · 큐브별 반사층 / 출력 품질

## 사용법

`Dimention R3F → 디멘션`에서 큐브별 층 수를 0–24로 조절합니다.
큐브 1은 초기 자세의 위쪽, 2는 왼쪽 아래, 3은 오른쪽 아래이며 회전 후에도 같은 오브젝트를 가리킵니다.
0은 해당 큐브의 내부 디멘션만 끄며 바깥 유리·조명·모션은 유지합니다.
값은 기존 자동 저장 경로에 함께 보관됩니다. 예전 세팅은 기존 `mirror.bounces`를 세 큐브에 동일하게 복제하여 읽습니다. 초안/A세팅 파일은 수정하지 않습니다.

## PNG / 4K MP4

- PNG: 이미지 출력 크기를 `4K · 현재 판형 유지` 또는 `아트보드 원본 크기`로 선택합니다.
- MP4: 출력 크기를 `4K · 현재 판형 유지`로 선택합니다. 긴 변이 3840px이며 가로 16:9는 3840×2160, 세로 9:16은 2160×3840입니다.
- 슈퍼샘플링은 두 출력에 공통 적용됩니다. GPU 안전 예산(전체 렌더 16MP)에 따라 실제 배율을 제한하며 출력 픽셀 아래로는 줄이지 않습니다. 2160×3840, 2× 요청은 약 1.389× 실제 렌더 후 다운샘플됩니다.
- 16MP보다 큰 이미지 요청은 안내 오류를 반환합니다. 기존 8MP 렌더→거대 PNG 확대 경로는 제거했습니다. 5940×8410의 네이티브 인쇄 렌더는 현재 지원하지 않습니다.
- PPI는 인쇄 크기 메타데이터이며 영상 해상도나 광학 샘플 수가 아닙니다.

## 품질 수정

1. R3F의 자동 카메라 프러스텀 덮어쓰기를 막고 CameraRig가 구도를 소유합니다. 캡처 크기/DPR은 Canvas의 실제 props에도 반영하여 재렌더 중 미리보기 해상도로 되돌아가지 않습니다.
2. 저장은 RAF 대기 횟수가 아닌 composer 후 완료된 렌더 프레임 수를 확인합니다. 해상도 안정화·GPU 연결·시간 초과를 검사하고 내보내기 중 편집/중복 내보내기를 잠급니다.
3. 반사 버퍼는 이미지에도 네이티브 4K 수준(8.4MP 예산)을 사용하며 mipmap을 생성합니다. MSAA 샘플이 0으로 복귀하지 않던 useFBO 경로 대신 명시적으로 할당/해제합니다.
4. 디멘션의 절차적 경계에는 `fwidth` coverage를 적용하고 서브픽셀 반사층을 부드럽게 감쇠시킵니다. 지오메트리 MSAA만으로 해결되지 않는 셰이더 내부 경계를 대상으로 합니다.
5. 환경 캡처는 미리보기 512, 출력 1024. 미리보기 DPR은 패널 값을 실제로 적용합니다. RGB/디멘션 보조 표면을 확대 배치하지 않아 외곽 이중 띠를 줄입니다.

## 한계 / 정직한 품질 기준

실시간 MeshPhysicalMaterial + 화면 공간 재귀 반사이며 물리 기반 다중 바운스 패스 트레이서가 아닙니다. 층 수는 광학 표현의 최대 경계 수로, 흡수·시점·축소율에 따라 모든 층이 선명하게 보이지 않을 수 있습니다. 화면 밖 정보/서브픽셀 하이라이트/8-bit H.264 4:2:0 색 경계에는 한계가 있습니다. 노이즈/계단현상 완전 0을 보장하지 않습니다. 픽셀 버퍼 예산은 VRAM 가용량 측정값이 아니므로 저사양 GPU에서 추가 제한이 필요할 수 있습니다.

## 검증

`scripts/verify-dimension-quality.mjs`는 별도 포트 41748에서 현재 설정의 복사본으로 검사합니다. `--4k`는 2160×3840 PNG와 3프레임 H.264 MP4를 생성합니다. 실제 사용자 설정과 5173 서버 저장 파일에는 쓰지 않습니다.
입력 fixture 기본 경로는 `.pleos/pre-dimension-quality-state.json`이며, 없는 경우 기본 세팅을 사용합니다. 최종 결과는 `artifacts/dimension-quality/validation.json`에 기록됩니다. 긴 전체 영상 검증과 짧은 인코딩 검증을 구분해야 합니다.

### 기존 회귀 검사에서 확인한 미해결 항목

2026-09-10 Chrome Metal에서 `verify:dimention-r3f`의 극단 밝기/루프 명도 두 항목은 현재 코드와 변경 전 초안 소스 양쪽에서 실패했습니다. 검사 임계값을 느슨하게 바꾸지 않았습니다.

- 초안: 스트레스 최대 평균 명도 218.81/255, 흰색 클리핑 비율 0.397. 현재 코드의 비교 실행: 190.59/255, 0.390. 조건은 master 3 / exposure 3 / bloom 1로, 여전히 과노출이 가능합니다.
- 루프 검사: 초안 최소/최대 평균 명도 비율 약 0.178, 현재 약 0.183 (기준 0.2). 서로 다른 시점의 명도가 크게 변하며, 이 실행에서 완전한 검은 프레임은 없었습니다. 이 테스트는 회전량이 1.25회인 상태도 포함하므로 실제 루프 연속성과 분리해 점검할 필요가 있습니다.
- 타입 검사, 빌드, 새 네이티브 4K PNG/짧은 MP4/투명 PNG/독립 슬라이더 검증 및 그 외 모드 회귀 검사는 별도로 통과했습니다. 전체 `verify` 통과로 표기하지 않습니다.
