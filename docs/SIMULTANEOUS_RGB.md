# 동시 RGB 조명 — Dimention R3F

후속 보정: 현재 반사광원 프로파일과 면 채움 제거는 [MIXED_LIGHT.md](MIXED_LIGHT.md)를 참조하세요. 아래는 동시 RGB 전환 당시의 배치·세팅 기록이며 현재 광원은 서로 겹치는 finite softbox 방식입니다.

레드 → 그린 → 블루 70% 주도 시퀀스를 제거했습니다. 세 색의 시간 가중치는 항상 1/3이며, 광원 위상 간격을 좁혀 한곳에 합치지 않습니다. 큐브 회전·유리 재질·디멘션 레이어·카메라·출력 설정은 유지합니다.

실제 스포트라이트와 광학 보조 패스는 같은 고정 가중치를 사용합니다. 환경 반사용 광원은 여섯 방향에 RGB 3개씩 배치된 18개의 부드러운 타원 발광면입니다. 주 렌더 장면에는 보이지 않으며 환경 캡처를 통해 유리에 반사됩니다. 큐브 표면에 컬러 텍스처를 입히거나 화면에 RGB를 합성하지 않습니다. 세 색을 공간적으로 분리하고 벽 방향마다 색 순서를 다르게 하여 한 방향에서 한 색만 보이는 구간을 줄였습니다. 환경 광원에도 해당 색의 활성화/강도 설정이 적용됩니다.

현재 사용자 세팅에 적용한 조명 보정:

| 항목 | Red | Green | Blue |
| --- | --- | --- | --- |
| 세기 | 1.15 | 0.95 | 1.00 |
| 각도 | 0.85 | 0.85 | 0.85 |
| 페넘브라 | 0.92 | 0.92 | 0.92 |
| 거리 / 감쇠 | 28 / 1.35 | 28 / 1.35 | 28 / 1.35 |
| 회전 반경 / 수직 진폭 | 5 / 3.1 | 5 / 3.1 | 5 / 3.1 |
| 위상 | 0° | 120° | 240° |

화이트 전체 세기는 2.54 → 0.65, 화이트 면광원 세기는 20 → 1.5로 낮춰 RGB를 덮던 과도한 흰 반사를 줄였습니다. 다른 조명 중심 좌표·색상·속도·노출 등은 유지했습니다. 이 값은 자동 저장되는 사용자 세팅이며 다른 저장 프리셋을 강제로 덮어쓰는 마이그레이션은 없습니다. 기존 세팅 사본은 로컬 `.pleos/pre-simultaneous-rgb-state.json`에 있습니다. 초안 스냅샷은 변경하지 않았습니다.

`node scripts/verify-simultaneous-rgb.mjs`는 해당 사본을 별도 포트에서 읽고 0 / 2.5 / 5 / 7.5 / 10 / 12.5 / 14.9초를 PNG로 비교합니다. 결과는 `artifacts/simultaneous-rgb/`에 저장합니다. 색별 밝기 우세 픽셀 비율은 존재 확인용이며 세 색이 화면 면적을 정확히 1/3씩 차지한다는 뜻이 아닙니다. 반사각·가림·현재 설정에 따라 보이는 비율과 밝기는 변합니다.
