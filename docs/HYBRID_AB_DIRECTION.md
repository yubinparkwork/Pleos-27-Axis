# A/B 하이브리드 — 설계 기준과 검수 항목

이 문서는 제작 방향과 수용 기준을 정한다. 기능 구현, 출력 검증, 인쇄 교정 또는 현장 보정의 완료 기록은 아니다.

## 기준이 되는 두 표현

| 기준 | 가져올 특성 | 하이브리드에서의 역할 |
| --- | --- | --- |
| A · 09.14 큐브 원본 | 큐브 안쪽의 광학 밀도, 굴절 왜곡, 겹치는 RGB 반사 | 내부 깊이와 색의 풍부함 |
| B · 현재 디멘션 | 선명한 얇은 축, 읽기 쉬운 층, 억제된 외곽 큐브 면, 현재 모션 | 기본 구조와 움직임 |

A의 원본 출처는 [09.14 큐브 기록](CUBE0914_MOTION.md)을 따른다. A/B는 이번 비교를 위한 표현 이름이며, 과거 렌더러의 동명 조명 설정이나 저장 프리셋과 동일하다고 가정하지 않는다.

## 설계 계약

### V4 — 열린 면의 광학 숄더

25엑시스 연결 보정: 하이브리드 층에도 연속적인 `uIdentityMix` 기반 새김·확장 단계를 적용한다. 등장 스태거 0을 즉시 켜짐으로 처리하지 않는다. 좁은 초기 반사광의 피크를 보상하고, 광학 숄더와 다중 반사는 새김 이후 확장한다. 같은 층의 윤곽에서 회색 면 제거 마스크를 산출한다. 반복 층 페이드는 전환 후반에 점진적으로 재결합한다. 전환 완료/미사용 상태의 V4 결과와 원본 A/B 셰이더는 보존한다. `node scripts/verify-hybrid-transition.mjs`는 시작 1ms 경계, 30fps 전환 프레임, 종료 경계, V4 완료 화면 동일성, 스태거·짧은 전환과 MP4를 검사한다. 결과는 `artifacts/hybrid-transition/`이다.

V3가 선형 반사 위주로 보이는 것을 보완한다. 기존 열린 가상 반사상 안에 넓은 Gaussian 광학 숄더를 추가하고, 연속적인 3D 법선으로 어긋난 반사광을 샘플링한다. 원래 Axis, 뒤쪽 개방, 레이어 등장·페이드 및 RGB 순환은 그대로다. 빛의 범위는 면 위의 부드러운 aperture로 제한하여 평면 전체가 단색으로 채워지지 않도록 한다. 실제 다중 산란의 물리 시뮬레이션이 아닌 광학 반사상 연출이다.

- `hybridFaceReflection`: 0–2, 기본 .7. 0은 V3와 픽셀 비교 가능.
- `hybridFaceWidth`: 0–1, 기본 .5. 원래 층 크기에 비례한 반사 폭.
- `hybridRefractionOverlap`: 0–1, 기본 .55. 어긋난 굴절 반사광의 비중.
- 추가 계산은 처음 8개 반사층에 한정하며 이후 층과 총 50겹 제한은 유지한다. 조명 강도가 0이면 추가 빛도 0이다. 개방 0에서는 추가 반사를 끄므로 V2 비교도 유지된다.
- 카메라·조명·개인 설정을 초기화하지 않는다. 새 필드만 기본값으로 보완한다. QA: `artifacts/hybrid-face/`.

### V3 수정 — A의 반사 구조 자체 개방

V2에서 A의 반사상이 큐브 뒤쪽 끝면을 따라 닫히던 문제를 수정했다. `hybridOpening`(0–1, 기본 1)은 광학 영역의 중심을 각 큐브의 원점 반대 방향으로 이동하고 반길이를 같은 양만큼 증가시킨다. 따라서 Axis 쪽 세 평면은 고정되고, 반대쪽 끝면만 멀어진다. 모든 가상 반사층에도 같은 한쪽 확장을 적용한다. 층의 폭·곡률·감쇠는 늘어난 박스 크기가 아니라 원래 층 크기로 계산하므로 A의 둥근 광학 표현을 유지한다.

완전 개방에서 먼 끝면은 내부 반사 경계로 쓰지 않는다. 이전 큐브 경계에서 갑자기 잘리는 마스크가 아니라, 그 경계를 통과해 계속 이어지는 반사상이다. 먼 영역에는 연속적인 밝기 감쇠가 있다. 완전한 무한 볼륨이나 물리적으로 닫힌 유리를 재현하는 것은 아니다. 부분 개방에서는 이동한 뒤쪽 끝면이 보일 수 있다.

0에서 V2 보관본과 같은 렌더로 복귀하는 픽셀 검사를 수행한다. A/B 원본과 V2 보관본 `saved-20260921082636619`는 변경하지 않는다. 카메라·광량·모션 설정은 그대로 두고 새 개방 값만 기본 1을 사용한다. QA 결과는 `artifacts/hybrid-open/`에 저장한다.

### V2 수정 — A의 광학 구조 복원

V1은 B의 가상 레이어에 약한 변형만 더해 A의 특징이 부족했다. V2는 `hybridOptics.glsl`에서 A의 유한 큐브 입사면과 Snell 굴절, 둥근 내부 반사상 법선을 사용한다. `traceGlass`의 실제 내부 다중 반사도 활성화한다. 외부 첫 반사만 0.035배, 반사 없는 직접 투과만 0.12배로 억제하고 내부 반사 출사 경로는 유지한다. B에서는 얇은 Axis 경계 레이어 하나와 기존 모션·등장 타이밍을 가져온다.

이는 A/B 이미지 페이드 혼합이나 큐브 면의 색칠이 아니다. 실제 유리 경계 광선 추적과 연출된 가상 반사상의 조합이며, 완전한 물리 패스 트레이싱은 아니다. 굴절 시점에 따른 내부 형상의 변화와 유한 큐브의 일부 실루엣은 남는다. 과도한 카메라 회전에서 B처럼 무한한 열린 공간을 보장하지 않는다.

이전 통합안은 `saved-20260921073913986` 로컬 스냅샷과 `artifacts/hybrid-ab/`에 보존한다. V2 QA는 `artifacts/hybrid-ab-v2/`에 따로 저장한다. 사용자 A/B/이름별 설정은 덮어쓰지 않는다.

- 공유 원점, 30° 투영, 세 입체의 관계와 승인된 실루엣을 유지한다. 얇은 축은 작은 화면과 정지 화면에서도 식별되어야 한다.
- B의 층 구조와 모션을 기준으로 삼는다. A의 질감을 더하기 위해 모션 타이밍, 축의 방향 또는 카메라 경로를 임의로 바꾸지 않는다.
- 외곽 큐브 면의 시각적 비중은 낮게 유지한다. 내부에는 굴절된 반사, 겹치는 색, 깊이에 따른 명암 차이를 더한다. 외곽 면을 다시 강하게 채워 내부 층을 가리지 않는다.
- 굴절 왜곡은 내부에 집중한다. 축과 층의 방향이 흐려지거나 형태 전체가 번지는 지점까지 확장하지 않는다.
- 메인은 RGB가 함께 읽히는 균형형으로 잡는다. 균형은 세 색의 화면 면적이나 수치를 정확히 1/3로 맞춘다는 뜻이 아니다.
- 정적 파생안은 R 우세 / G 우세 / B 우세의 세 가지로 구성한다. 한 색을 주도적으로 보이게 하되 다른 색의 반사와 내부 깊이가 남도록 한다.
- A 원본, B 기존 설정, 이름 붙인 스냅샷은 비교 기준으로 보존한다. 하이브리드의 저장값과 결과물은 별도로 구분한다.

## 매체 적용 방향

| 용도 | 구도와 선택 기준 | 확인할 점 |
| --- | --- | --- |
| 메인 KV | 축의 결절점과 세 방향의 관계가 읽히는 전체 또는 준전체 구도 | 제목·행사 정보가 들어갈 여백, RGB 균형 |
| 부분 KV / 크롭 | 결절점 또는 방향을 설명하는 축 일부와 내부 반사를 함께 선택 | 확대해도 의미 없는 빛무늬로만 보이지 않는지, 재단 후 핵심 축이 남는지 |
| POP / 안내물 | 메시지 영역과 그래픽 영역을 나누고 R/G/B 우세안을 매체별로 선택 | 실제 크기와 관람 거리에서 문구, 축, 층이 서로 구별되는지 |
| 디지털 모션 | B의 움직임 위에서 내부 반사와 RGB가 변하는 흐름 | 밝은 순간에도 축이 유지되는지, 반복 경계와 주요 정지 프레임의 완성도 |

같은 화면을 모든 판형에 자동 확대·재단하는 방식으로 확정하지 않는다. 세로형·가로형·작은 POP를 각각 검토하고, 전체 KV와 부분 KV가 같은 표현 체계로 읽히도록 크롭 위치와 색의 주도권을 조정한다.

## 디지털 마스터와 인쇄 확인

- 디지털 마스터는 sRGB 기준으로 관리한다. 화면용 PNG/영상과 인쇄 제작 파일의 용도를 구분한다.
- 인쇄소의 용지·인쇄 방식·ICC 프로파일을 확인한 뒤 소프트 프루프와 테스트 인쇄를 진행한다. 이 문서에서 공통 CMYK 수치나 잉크 총량을 확정하지 않는다.
- 테스트에서는 어두운 내부 층의 분리, 채도가 높은 RGB의 변화, 얇은 축의 재현, 크롭과 텍스트의 가독성을 확인한다. 화면에서 보이는 발광감이 인쇄에서 동일하게 재현된다고 전제하지 않는다.
- 짙은 검정이 전면을 덮는 풀블리드 시안을 바로 본 인쇄로 넘기지 않는다. 부분 KV와 여백을 둔 배치를 함께 비교하고, 실제 출력 확인 후 배경 범위와 명암을 결정한다.
- 최종 크기, 재단·도련, 필요한 해상도는 해당 매체와 제작처 조건을 확인해 정한다. 고해상도 sRGB 이미지의 존재만으로 인쇄 교정 완료라고 표시하지 않는다.

## V6 · 내부 면 반사 경로

V5의 넓은 pocket 그라데이션은 제거했다. 원본 A의 닫힌 rounded-cube 교차, Fresnel/TIR, 이웃 큐브 투과 계산을 별도 광학 proxy에 사용한다. 외부 반사와 bounce 0 직접 투과는 출력하지 않으며, 한 번 이상 내부 반사된 후 빠져나온 빛만 열린 표현에 더한다. 열린 면을 닫힌 proxy로 연속 압축하는 좌표 매핑은 미술적 근사이며 열린 유리의 물리적 정답은 아니다. 후면은 primary ray에 보이지 않는다.

`scripts/verify-hybrid-internal.mjs`는 bounces=1에서 V4와 같고, 16에서 실제 내부 반사 경로가 추가되는지 검사한다. 개인 설정 및 A/B 원본은 변경하지 않는다.

## V5 · 열린 내부 반사면 (보관된 이전 방식)

V4의 얇은 반사 띠 안쪽에 폭을 가진 반사면을 추가한다. 반사면 내부에서 광학 법선이 완만히 변하며 동일 RGB 광원을 반사해 그라데이션을 만든다. 축의 경계를 덮지 않고, 먼 쪽은 부드럽게 사라져 닫힌 후면을 만들지 않는다. 실제 추가 큐브나 발광 면이 아닌 미술적으로 구성한 가상 반사상이다.

기존 면 반사 강도·폭·굴절 겹침 컨트롤을 재사용한다. 강도 0은 V3로, 뒤쪽 열림 0은 V2로 돌아간다. A/B 원본, 사용자 설정, 25엑시스 전환의 시간 구조는 유지한다. 전환 검사에서 회색 시작 화면은 그대로이며 완성 화면은 V4 대비 의도적으로 달라진다.

## Hall D 공간 적용의 범위

Hall D의 실제 평면·입면, 화면의 형상과 치수, 설치 위치, 관람 위치 자료는 아직 이 방향 문서의 전제로 확보되지 않았다. 현재 검토할 수 있는 것은 화면 안쪽으로 층이 이어지는 개념적 깊이 테스트다.

이를 Hall D에 맞춘 원근 보정, 아나모픽 착시 또는 현장 시뮬레이션 완료로 표현하지 않는다. 현장 적용은 자료 확보 후 화면 경계·시점·밝기·재생 조건을 반영해 별도로 검수한다.

- [ ] 균형형 메인과 R/G/B 우세 정적 세 안이 서로 구별되며 같은 구조를 공유한다.
